# Changelog

## 0.1.0-alpha.1

Initial public alpha preparation:

- React + StyleX reference components and source-owned install tooling.
- Native Web Components / Vanilla adapter for the cross-framework core.
- Vue 3, Svelte, and Solid adapters for the same 11-component core slice.
- Five original MIT screen recipes with fictional, replaceable fixtures.
- Interactive docs, generated registry contracts, MCP discovery, and alpha
  release checks.

The larger React catalogue and full screen recipes are not yet advertised as
cross-framework complete. Vue, Svelte, Solid, and Vanilla coverage expands only
when each component has target-specific behavior and accessibility evidence.
