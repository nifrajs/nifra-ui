# @nifrajs/ui

StyleX-powered, source-owned React components with a machine-readable design
contract. Use the package directly or copy components into your app with
`@nifrajs/ui-cli`.

The runtime package supports React 18.3+ and React DOM. Framework-free native
custom elements are shipped separately as `@nifrajs/ui-elements`; Vue, Svelte,
and Solid adapters for the cross-framework core are shipped as
`@nifrajs/ui-vue`, `@nifrajs/ui-svelte`, and `@nifrajs/ui-solid`. The token
stylesheet, registry, screen manifests, and event/state contracts are
framework-neutral. The other React-only components are labeled planned for
those adapters until native parity evidence exists.
